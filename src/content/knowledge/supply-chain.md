## 概述

供应链管理是对从原材料采购到最终产品交付给消费者的整个流程的计划、执行和控制。

## 核心模块

### 1. 需求管理

#### 滚动计划
- **月度滚动**: 每月更新未来 3 个月的计划
- **周度滚动**: 每周更新未来 4 周的计划
- **关键指标**: 预测准确率、计划达成率

#### 需求预测方法
| 方法 | 适用场景 | 准确度 |
|------|----------|--------|
| 移动平均法 | 需求稳定 | 中 |
| 指数平滑法 | 有趋势 | 中高 |
| Prophet | 有季节性 | 高 |
| ARIMA | 复杂模式 | 高 |

### 2. 库存管理

#### 库存分类（ABC 分析）
- **A 类**: 占总价值 70% 的少数 SKU
- **B 类**: 占总价值 20% 的 SKU
- **C 类**: 占总价值 10% 的大量 SKU

#### 安全库存计算
```
安全库存 = Z × σ × √LT
Z: 服务水平对应的标准差倍数
σ: 需求标准差
LT: 补货提前期
```

#### 库存周转率
```
库存周转率 = 销售成本 / 平均库存
健康值: 6-12 次/年（视行业而定）
```

### 3. 采购管理

#### 供应商评估维度
1. **质量**: 来料合格率
2. **交期**: 准时交付率
3. **成本**: 价格竞争力
4. **服务**: 响应速度与配合度

#### 采购订单流程
1. 需求确认 → 2. 供应商选择 → 3. 订单创建 → 4. 订单跟踪 → 5. 收货验收 → 6. 对账付款

### 4. 仓储管理

#### 仓库布局原则
- **高频物料**: 靠近出货口
- **重物**: 低层货架
- **轻物**: 高层货架
- **关联物料**: 相邻存放

#### 库存准确率
```
库存准确率 = (1 - 盘点差异项数 / 总盘点项数) × 100%
目标值: ≥ 99.5%
```

### 5. 物流配送

#### 运输方式选择
| 方式 | 时效 | 成本 | 适用场景 |
|------|------|------|----------|
| 空运 | 3-5 天 | 高 | 高价值、紧急 |
| 海运 | 20-40 天 | 低 | 大批量、不紧急 |
| 铁路 | 10-15 天 | 中 | 中欧班列 |
| 卡车 | 1-3 天 | 中 | 国内短途 |

## 跨境电商特殊考量

### FBA 物流
- **头程**: 国内仓 → 亚马逊 FBA 仓
- **尾程**: 亚马逊配送
- **关键指标**: IPI 分数、库存绩效

### 海外仓
- **功能**: 存储、分拣、配送
- **优势**: 降低物流成本、提升时效
- **挑战**: 库存管理复杂度增加

## 数据分析指标

### 供应链 KPI
1. **订单满足率** (Fill Rate): ≥ 95%
2. **库存周转天数** (DOI): 视行业而定
3. **准时交付率** (OTD): ≥ 98%
4. **供应链总成本** (TSC): 持续优化

### 预测准确性
- **MAPE** (平均绝对百分比误差): ≤ 20% 为良好
- **Bias** (偏差): 接近 0 为佳
